# ESAP - Conversor PDF

Bienvenido a la documentación oficial del **ConversorPDF**.

Este proyecto es un complemento (Add-in) para Microsoft Excel que facilita la manipulación de archivos PDF, la gestión de viáticos y la firma digital de documentos dentro de la ESAP.

## Secciones Principales

-   [**Artículos**](articles/intro.md): Guías de usuario y arquitectura.
-   [**Referencia API**](api/index.md): Documentación técnica de las clases y métodos desarrollados en C#.

## Características

-   Combinación de múltiples archivos PDF.
-   Procesamiento masivo e individual de viáticos.
-   Extracción de texto desde PDFs a celdas de Excel.
-   Firma digital integrada.

Para comenzar, revisa la [Introducción](articles/intro.md).
